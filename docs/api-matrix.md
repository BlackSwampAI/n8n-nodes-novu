# Advertised operation matrix

This matrix is the editor-facing acceptance contract for `@blackswampai/n8n-nodes-novu@0.1.0` through Batch 8. Detailed request/response schemas and official source links remain canonical in [API coverage](API_COVERAGE.md). “Cloud” means the currently documented Novu API; self-hosted compatibility is unverified.

| Resource / operation            | Automation value                                       | Endpoint / edition                                        | Visible and required controls                                                                                    | Minimum valid state / blank behavior                                                | Output                                         | Side effects                                                                                                 | Test tiers                                                |
| ------------------------------- | ------------------------------------------------------ | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------- |
| Notification / Trigger Workflow | Start an existing workflow for one subscriber or topic | `POST /v1/events/trigger`; Cloud                          | Workflow Identifier, Recipient Type, subscriber ID or Topic Key, Payload; optional transaction/idempotency/retry | Nonempty identifiers and object payload; invalid/blank input fails locally per item | Full validated acknowledgment                  | Sends for processing; topic uses Novu fan-out; acceptance is not delivery; optional bounded idempotent retry | Metadata/unit/mock execution; live/editor pending         |
| Notification / Cancel Execution | Cancel eligible pending notification work              | `DELETE /v1/events/trigger/{transactionId}`; Cloud        | Required Transaction ID                                                                                          | Nonempty transaction ID; blank fails locally                                        | Transaction ID and actual boolean cancellation | Cancels active/pending delays or digests; cannot recall delivered messages                                   | Metadata/unit/mock execution; live/editor pending         |
| Workflow / Get                  | Inspect one existing workflow                          | `GET /v2/workflows/{workflowId}`; Cloud                   | Required Workflow locator, From List or By ID                                                                    | Nonempty public workflowId; blank/malformed locator fails locally                   | Full workflow                                  | Read only                                                                                                    | Metadata/unit/mock execution; live/editor pending         |
| Workflow / Get Many             | Enumerate workflows and populate selection             | `GET /v2/workflows`; Cloud                                | Return All or Limit; optional query/status/tags/order                                                            | Defaults valid; malformed filters/options fail locally                              | One item per workflow; empty emits zero        | Read only; offset/limit paging; manual IDs survive list permission errors                                    | Metadata/unit/mock pagination/search; live/editor pending |
| Subscriber / Create or Update   | Synchronize a recipient profile                        | `POST /v2/subscribers`; Cloud                             | External Subscriber ID; optional profile/data and Fail If Exists                                                 | Nonempty external ID; omitted fields remain omitted                                 | Full subscriber                                | Creates or upserts; strict option rejects duplicates                                                         | Metadata/unit/mock execution; live/editor pending         |
| Subscriber / Get                | Retrieve one recipient                                 | `GET /v2/subscribers/{subscriberId}`; Cloud               | External Subscriber ID                                                                                           | Nonempty ID; blank fails locally                                                    | Full subscriber                                | Read only                                                                                                    | Metadata/unit/mock execution; live/editor pending         |
| Subscriber / Get Many           | Enumerate matching recipients                          | `GET /v2/subscribers`; Cloud                              | Return All or Limit; optional filters/order                                                                      | Defaults are valid; malformed filters fail locally                                  | One item per subscriber; empty list emits zero | Read only; forward cursor paging                                                                             | Metadata/unit/mock pagination; live/editor pending        |
| Subscriber / Update             | Patch selected profile fields                          | `PATCH /v2/subscribers/{subscriberId}`; Cloud             | External ID; selected Fields/Clear Fields                                                                        | At least one explicit change; no-op fails locally                                   | Full subscriber                                | Changes only selected fields                                                                                 | Metadata/unit/mock execution; live/editor pending         |
| Subscriber / Delete             | Remove a recipient                                     | `DELETE /v2/subscribers/{subscriberId}`; Cloud            | External Subscriber ID                                                                                           | Nonempty ID; blank fails locally                                                    | Target ID plus actual acknowledgment/status    | Destructive subscriber deletion                                                                              | Metadata/unit/mock execution; live/editor pending         |
| Subscriber Preference / Get     | Read global/workflow preferences                       | `GET /v2/subscribers/{subscriberId}/preferences`; Cloud   | External ID; optional criticality/context keys                                                                   | Nonempty ID; malformed filters fail locally                                         | Full global/workflows envelope                 | Read only                                                                                                    | Metadata/unit/mock execution; live/editor pending         |
| Subscriber Preference / Update  | Change explicit channel preferences                    | `PATCH /v2/subscribers/{subscriberId}/preferences`; Cloud | External ID, Global/Workflow scope, workflow reference when scoped, six tri-state channels                       | At least one Enabled/Disabled channel; blank workflow reference/no-op fails locally | Full preference envelope                       | Changes selected settings; does not claim queued-work cancellation                                           | Metadata/unit/mock execution; live/editor pending         |
| Topic / Create or Update        | Maintain an audience container                         | `POST /v2/topics`; Cloud                                  | Topic Key; optional display name/data and Fail If Exists                                                         | Nonempty key; invalid data/limits fail locally                                      | Full topic                                     | Creates/upserts topic                                                                                        | Metadata/unit/mock execution; live/editor pending         |
| Topic / Get                     | Retrieve one topic                                     | `GET /v2/topics/{topicKey}`; Cloud                        | Topic Key                                                                                                        | Nonempty key; blank fails locally                                                   | Full topic                                     | Read only                                                                                                    | Metadata/unit/mock execution; live/editor pending         |
| Topic / Get Many                | Enumerate topics                                       | `GET /v2/topics`; Cloud                                   | Return All or Limit; optional key/name/order                                                                     | Defaults valid; malformed options fail locally                                      | One item per topic; empty emits zero           | Read only; forward cursor paging                                                                             | Metadata/unit/mock pagination; live/editor pending        |
| Topic / Update                  | Rename a topic                                         | `PATCH /v2/topics/{topicKey}`; Cloud                      | Topic Key and Display Name                                                                                       | Both required; blank/overlong name fails locally                                    | Full topic                                     | Changes display name only                                                                                    | Metadata/unit/mock execution; live/editor pending         |
| Topic / Delete                  | Remove topic and subscriptions                         | `DELETE /v2/topics/{topicKey}`; Cloud                     | Topic Key                                                                                                        | Nonempty key; blank fails locally                                                   | Target key plus actual acknowledgment          | Irreversibly deletes topic subscriptions                                                                     | Metadata/unit/mock execution; live/editor pending         |
| Topic Subscription / Create     | Add subscriber relationships                           | `POST /v2/topics/{topicKey}/subscriptions`; Cloud         | Topic Key and 1–100 subscriber/optional identifier entries                                                       | At least one valid entry; blank/malformed fails locally                             | Full `data/meta/errors?` envelope              | Creates relationships; Novu may auto-create missing topic; partial success possible                          | Metadata/unit/mock execution; live/editor pending         |
| Topic Subscription / Get Many   | Enumerate relationships                                | `GET /v2/topics/{topicKey}/subscriptions`; Cloud          | Topic Key, Return All/Limit; optional subscriber/context/order                                                   | Nonempty topic key; defaults otherwise valid                                        | One item per relationship; empty emits zero    | Read only; forward cursor paging; no uniqueness assumption                                                   | Metadata/unit/mock pagination; live/editor pending        |
| Topic Subscription / Delete     | Remove selected relationships                          | `DELETE /v2/topics/{topicKey}/subscriptions`; Cloud       | Topic Key and 1–100 subscriber/identifier selectors                                                              | At least one valid selector; blank/malformed fails locally                          | Full `data/meta/errors?` envelope              | Subscriber-only selector removes all its relationships in topic; partial success possible                    | Metadata/unit/mock execution; live/editor pending         |

All executions resolve controls per input item and preserve n8n pairing/continue-on-fail behavior. The package has no live API, actual editor, self-hosted, delivery, or Creator Portal evidence yet.
