# Batch handoff template

Copy this structure into `docs/STATUS.md` for each completed batch; replace every prompt with observed facts.

## Batch N: name

- Status, branch, pull request, merge commit, and post-merge default-branch CI
- Package name/version and whether publication remains blocked

### Delivered

- User-visible operations and deliberately deferred scope
- Contract, destructive-action, pagination, partial-result, and retry decisions

### Evidence

- Official sources and review date
- Deterministic test count and covered behavior
- Exact local/CI commands and results
- Workspace-load and isolated packed-install results
- Live Novu, actual n8n editor, self-hosted, delivery, and Creator Portal results—or the exact reason each was skipped
- Versions/editions actually exercised; never infer compatibility

### Open issues

- Concrete blockers and unresolved upstream behavior
- Required cleanup or release checkpoint

### Next batch

- Name and why it follows, without adding scope
